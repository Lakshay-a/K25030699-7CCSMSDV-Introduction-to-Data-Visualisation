# Wealth, Education, and Development: Interactive Data Visualisation

This project is an interactive D3.js data visualisation web application developed for the **7CCSMSDV Introduction to Data Visualisation** module at **King’s College London**.

The visualisation explores the relationship between **wealth, education, and development** across countries by combining data from the **Global Data Lab International Wealth Index** with global education indicators. Through interactive charts and visual storytelling, the application highlights how wealth and secondary school enrolment vary across countries, continents, and over time.

## Project Overview

This project investigates patterns of global inequality and development using interactive data visualisation techniques. The analysis focuses on:

- Trends in wealth and secondary education enrolment over time
- Differences in wealth and education outcomes across continents
- Countries that outperform or underperform relative to broader global development patterns

## Dataset

The visualisation combines:

- **Global Data Lab International Wealth Index (IWI)**
- Global education indicators, including secondary school enrolment data

The merged dataset covers the period **1999–2023** and enables comparative analysis of wealth and education outcomes across countries.
